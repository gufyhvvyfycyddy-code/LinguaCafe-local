# Publication Allowlist

The public repository may contain material needed to review and build the project, including:

- application source code;
- tests and synthetic fixtures;
- migrations and schema definitions;
- dependency manifests and lock files;
- build configuration without private runtime values;
- ADRs, architecture documents, product contracts and acceptance evidence;
- public release documentation;
- anonymized examples;
- platform source projects and non-private release metadata;
- upstream attribution and license notices.

Every candidate still receives a final privacy, credential and redistribution check before publication.

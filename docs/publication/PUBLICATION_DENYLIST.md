# Publication Denylist

Do not intentionally publish:

- private credentials or authentication material;
- signing material;
- authenticated browser/session state;
- real user databases or personal learning history;
- real user identity/profile data;
- private runtime configuration;
- local MCP/agent sessions;
- debug captures containing private request data;
- build caches, dependency directories or temporary test debris;
- unreviewed local worktree assets;
- third-party content without confirmed redistribution rights.

A filename or extension alone is not proof that a file is safe to publish.
